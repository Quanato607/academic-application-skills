# Example: Recommendation Letter Request

```text
Use $phd-recommendation-letter to draft a very strong PhD recommendation letter.

Inputs:
- Candidate CV: /path/to/candidate_cv.pdf
- Target: PhD application in machine learning and biomedical AI
- Recommender: Professor X, corresponding author on the candidate's first-author journal paper
- Directly observed work: one research project, weekly meetings, experiment reviews, manuscript revisions
- Indirect CV facts: other publications and internships should be framed as broader trajectory
- Requested strength: very strong, but no numeric percentile unless the evidence ledger supports it

Return:
1. Letter Draft
2. Evidence Ledger
3. Score
4. Risk Fixes
```
